# Playbook 08 · 从财报发现选题与主图

首次研究和续期先运行 `start_report.py`。用同批原件的 `editorial-opportunities.json` 和 `capabilities.json` 找阅读起点。前者将原件全文中的线索归到物理页，后者说明账本已支持的关系。逐页核查公司独有的经营表、会计附注和管理层解释。读回金额、列标题、范围和比较期。关键词只给线索。漏匹配不能证明未披露。发现未映射的重要附注，按现有未映射协议处理。季报信息有限时，有理由的短稿可以胜过无证据的全年叙事。

## 选题要改变读者的判断

1. 先画出公司的经济关系。确认谁付款、公司保留什么收入、哪些合同或投入形成成本、什么时候确认收入和收到现金、谁承担损失。优先追反常变化、相关指标背离或聚合数字隐藏的分化。直读经营附注，避免被标准科目清单决定选题。
2. 比较至少两个确有竞争力的问题。逐题写它可能改变哪条判断、决胜披露、可复算的金额或比率、还缺的证据。选最能改变判断且可落实到源格的一个。另一个可以压缩成辅助证据，或列出需要补的具体披露和比较口径。季度披露只支持一个问题时，如实将竞争问题延期。
3. 围绕主论点量化机制，用最强替代解释决定还要查哪张表。用同口径贡献桥、分部量级和利润率、净利润到现金调节、报告实际披露的平均余额等拆解。能闭合的算术先闭合。若剩余项混合了多个因素，保留剩余项的含义。快增长业务未必贡献最多毛利，期末余额和期间现金调节不能代用。

| 读到的现象 | 有区分力的下一步 |
|---|---|
| 同期毛利修复、现金转弱 | 复算集团毛利增量和各产品本期毛利；用现金流补充资料定位调节量；另查在手订单、库龄或回款披露，区分占用机制与实际原因。 |
| 银行扩表、利息收入下降 | 先核对可比平均生息资产、资产利息收入、付息负债成本。把规模和其余余额组合、收益率与交互成分分别表述。 |
| 保险利润远超保费增速 | 分清统计保费、法定保险服务收入、投资估值及保险财务影响。用两期法定营业利润贡献和保险合同计量检验假说。 |
| 重述、并购、负基数或融资紧约束 | 查两期的更正版本和合并范围。用绝对金额、同口径子集或期限结构检验。对可能冲掉论点的比较基础变化给出实际影响。 |

把决策写入既有 `research-brief.json` 的 `editorial_selection`。`lead_thesis_id` 指向已按源键、Decimal 关系、替代解释和下期反证验证的 thesis。每个候选写可以追溯的取舍。以下结构为示意，源键和图 ID 用本报告真实数据填写。

## 先构思证据，再决定图形和文章节奏

对同一结论比较两种合法表达。选能在手机上读出关键差异、能回答原问题且最少依赖图外解释的一种。图的任务是让读者定位、比较或复算。写出从画面上能指认的答案、备选与取舍。如果一两行文字和核对表已能传达全部含义，`figure_id` 写 `null`，在 `tradeoff` 说明文字路径。

首屏标题、导语和主数字先让核心张力成立。按适用规范安放完整利润主图。若首图交代完整会计链，而关键论证来自现金、分部或风险结构，尽早安放能回答标题的证据图，将它写入 `lead_exhibit`。后一张图应提供首图读不出的信息。读图顺序一般从矛盾、量化解释、限度或反证，再到附注对账。用移动端短标签直接标重要比较量，长标签和次要明细移入相邻正文或核对层；保留计量单位、正负号和源定义。

- 变化贡献用带零轴的签名桥。用同一金额尺度比较产品各自的收入与毛利；没有可比的上期收入与成本时，只讨论本期水平。
- `volume_rate` 用同口径流量与平均余额，规模效应以基期实际比率估算；剩余项保留比率、结构和交互。两时点余额另图。
- 只有完整守恒的收入分区及合适的正向利润结构才使用对应桑基。净利润调节到现金按原始调节项处理，附注与措辞保持会计语义。

按 [Playbook 09](09_SELF_DIRECTED_DELIVERY.md) 查看桌面、真实手机图和整篇。若遮住正文后读错比较基准，先改图中的层级和标注。若首屏承诺超过来源，回到研究稿重写判断，重新构建并复验。
