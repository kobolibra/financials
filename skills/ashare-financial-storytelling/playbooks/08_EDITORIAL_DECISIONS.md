# 新报告的研究与主编决策

## 打开原件后先决定读者应理解什么

初次运行产生账本、行业能力和可用关系。在既有 research-brief.json 的 editorial_selection 中比较两个有竞争力的问题。写出能改变选题的一项具体披露及页码。把管理层解释与由源格独立复算的变化分开。沿最可能推翻论点的路径再读一张表：例如产品收入增长时追成本、库存与实际销售，银行扩表时追平均余额、收益和信用成本。重大未映射行依现有协议处理。已知作者简报只用于重建和校准，盲测时隔离。

| 输入 | 首要判断 | 退回重读的情形 |
|---|---|---|
| 首次覆盖、年报 | 哪些业务真正留下毛利，现金和再投资怎样改变对盈利的理解 | 原件有产品成本，而正文只讲集团报表增减 |
| 半年报与季报 | 上期判断在本期哪条披露下加强、削弱或反转 | 把半年和单季的重叠窗口当作独立验证 |
| 重述、并购、负基数 | 比较基础如何改变结论，哪些指标仍可比 | 原披露、重述数、合并范围或百分点的分母混用 |
| 银行 | 规模、收益、负债成本、信用和资本中哪个机制支配本期变化 | 用期末存款代日均余额或把剩余项全部叫产品定价 |
| 金融与实体混合、保险、券商、地产 | 按会计和经营模型分别确认能解释的关系，披露稀疏时缩小论点 | 将统计保费当服务收入，或把签约额直接接入法定营收桥 |

## 从有效关系选择主图

先完成研究简报，再从 figure_candidates 复制或编写所需规格到 new_figures，按读者所需的证据顺序填写 order 与 roles。第一张为 primary。若最有信息量的关系超出当前适配范围，保留事实和研究，标明需开发的图或采用准确的表述。允许短报告。

- composition 为离线候选时，comparison 核对同一指标两期，signed_bridge 核对可加总的变动。图题问“多少转成利润”时要能追到完整传导及剩余项。几个余额并列只能支持各项分别变动的判断。
- volume_rate 输入 flow 和 average_balance 两个账本键，两者都应有同口径比较期。查原件确认流量确实对应这个平均余额，记录口径。规模效应按上期实际比率估计，剩余合并比率、结构与交互。该图支持量化会计分解。
- product_economics 的 products 填写若干［产品名、本期收入键、本期自身成本键］。取自同一张分产品表，核对行列。画本期收入与毛利的统一金额尺度。可选部分产品，说明范围；需要证明变动贡献时另取可比期精确数据。
- 在 article.metrics 中用账本宏或 claim 引入能改变读者理解的关键量。用 context 写清期间或假设。需要中文语义断行时使用 article.title_lines。避免连续四次复述同一数字。

## 交稿前打开最终 HTML

选一篇行业或任务相近的站内优秀作品作对照，实际查看桌面首屏、手机首屏、主图和完整阅读顺序。历史招行半年报可用于校准银行机制与首屏层级；不得移植其当期结论。对每一图做一次遮正文读图：记录能从标注直接读出的答案、仍然无法区分的解释、删图会失去的判断。图题超过证据时改题或加证据。双浏览器验证金额、文字和导出后仍须检查整篇。年度稿出现核稿提示即退回。

## 校准与成本

已有稿从原件复算、同一作者返工、陌生作者首次交付分别记账。冻结版本与陌生发行人后，只提供 PDF 和入口，以首次成稿评分。允许不同作者选出不同且成立的论点。分开记录重大错漏、已披露但遗漏的关键解释、实际读图误解、适当降级和通过评审前的时间。保存失败稿，修后进入回归。按行业、报告期与披露难度分别报告最弱表现。复用有相同原件 SHA 的提取结果；修正上游事实后重建依赖它的图和正文。独立 AI、真人与作者本人分别登记。
