# Playbook 03 · 图形系统：AEI 式财报视觉语法 + 本库渲染器映射

AEI 的财报图之所以一眼可读，靠的不是配色本身，而是几条稳定的信息设计规则：金额决定宽度；灰色=收入、红色=成本费用、绿色=利润；每个节点直接标注名称、金额、同比与利润率；从左到右只讲一条利润链；次要细节合并为有名称的小项；图上方一句话说明这季的事。本系统采用这些规则的**原创实现**，不复制其图像、品牌或字体，并加上 A 股会计合法性约束。

## 2. 节点标注规范（E1/E2 的目标规格）

AEI 收入图的每个节点都带三层信息。本库的目标规格：

```
节点名称（例：营业毛利）
金额（例：3.48亿）
同比 / 利润率（例：同比 +2.1% · 毛利率 34.8%（−4.1pp））
```

- 收入来源节点：金额 + 同比 + 自身毛利率（TYPE A 已实现毛利率；同比未实现）。
- 利润节点：金额 + 利润率 + 利润率 pp 变化。
- 成本/费用节点：金额 + 占收入比例。
- **当前缺口**：`full_profit_chain.py` 节点只标金额，不标同比与利润率。未实现前，把同比与利润率写进首屏指标、主图下方的"本期营业层主要金额构成"和 takeaway（用 `quantified_claims`），不要手打在图上。实现时必须：从同一账本的 `_prior` 事实计算、在 SVG `data-*` 属性中保存精确值、被 `profit_chain_audit.py` 独立复算，并对所有使用该渲染器的已发布报告做全量重建与浏览器验收。

## 3. 完整利润主线的版式问题（基于 2026-11-16 生产截图 300570 的自评）

真实 1440 截图显示了以下问题，这些也是渲染器下一轮改进的验收标准：

1. **近重复层占据画面**：营业利润 1.94、税前 1.95、合并净利 1.82、归母 1.76 四个节点几乎等宽，占了横向 60% 的空间，信息量很低。规格：相邻两层差额小于收入的 2% 时，在主图中合并为一段并在节点下注明"含营业外净额 +0.01亿、所得税 −0.13亿"，完整层级保留在核对表。
2. **费用分支远离来源**：费用节点被统一推到顶部，红色曲线跨越整幅图，读者难以对应。规格：费用节点放在所属利润层的正上方或正下方，标签贴近节点。
3. **极小分支不可见**：43.70 万元的分支只剩发丝线。规格：真实宽度不变（零就是零，极小就是极小），但小于 1% 收入的项目合并为"其他净额（N项）"并在图外列出全部项目；合并只改变**显示分组**，核对表逐项保留。
4. **正文首屏缺少同比**：见 §2。

以上 1–3 当前**未实现**；改动 `full_profit_chain.py` 会改变 14 份已发布报告的字节，必须作为单独 PR 全量重建并重新做生产验收。

## 4. 设计 token 与排版

- 颜色：收入源 `#9CABB2`；合计 `#263F47`；成本费用 `#CD7271`；利润 `#239878`；背景 `#F8F7F2`；纸面 `#FFFEFB`；正文 `#19333C`；辅助文字 `#617875`；负值使用铜色/红色并带"−"号。
- 字体：标题 Noto Serif CJK SC / 宋体回退；正文与数字 Noto Sans CJK SC，数字使用等宽数字 `font-variant-numeric: tabular-nums`。
- 字号：图中金额 ≥ 13px（手机 ≥ 12px），节点名称 ≥ 13px，脚注 ≥ 11px；任何金融标签 < 10px 是 FAIL。
- 标题：桌面 2–3 行内；不出现单字孤行（例："用。"独占一行是 FAIL）。
- 单位：亿元保留两位；百分比一位或两位；pp 表示百分点；正负号显式。
- 每张图：桌面 1040/1100 宽、手机 330 宽**两套原生构图**，不缩放、不横滑、不隐藏。

## 5. 图序节奏

- 第一屏只出现一张大图（完整利润主线）。
- 相邻两张图不能回答同一个问题；若利润签名桥（E4）只是主线的重画，让它进入核对区（编辑清单 `role: reference`）。
- 图与文交替：每 2–3 张图插入一段研究文字（`essays`），而不是把所有文字堆在最后。
- 反证与边界紧贴图下，不集中到附录。

## 6. 编辑清单（`research/editorial-20261113/<code>.json`）的角色

- `primary`：完整利润主线（自动）。
- `secondary`：回答新问题，留在正文。
- `reference`：已被主线覆盖或只供核对，折叠到"完整核对"区；`rationale` 写清为什么下沉。
- `summary: true` + `focus`：在正文留一张阅读卡，只展示 focus 中列出的关键行，并链接到完整原图。

选择标准见 `docs/PROFIT_CHAIN_EDITORIAL_STANDARD.md`：重要性同时看金额、占利润比例、同比贡献、方向变化与特殊风险，不用固定 Top3 或图表配额。
