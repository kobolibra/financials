# Playbook 05 · 质量评分与自评流程

自动门槛证明"没有错"；本评分回答"好不好"。每份报告发布前由执行者按下表打分并写进 PR 描述或 `release-gates.json` 的 `editorial_self_review` 字段。这是**执行者自评**，不是独立人类审稿，独立二审仍为 NOT_CHECKED。

## 1. P0 一票否决（任一出现即不发布或标为 source_limited_preview 并保持 PR 草稿）

- 任何数字与原件页/行/列/符号不符；恒等式不闭合；比较期错列。
- 负值画成正向流；存量与流量相加；父子分类相加；集团毛利率冒充业务毛利率。
- 同一聚合节点右侧按来源交错输出成本与毛利，导致应当分组的流带相互穿越；原始金额守恒但桑基流带几何交叉也属于发布 P0。必须由独立 SVG 端口次序检测和真实 Chromium/WebKit 截图共同验证；单纯绿灯数字测试不算完整视觉复核。
- 因果断言没有原文依据（会计差额写成价格/销量/汇率原因）。
- 手机端图形横滑、隐藏、缩到不可读；任何文字裁切或关键标签重叠。
- 正文出现机器标记、未替换的 `{{占位符}}`、手打舍入数。
- 使用旧截图或旧 CI 证明新字节。
- 趋势叙述与图中数据方向相反（例：写"逐季提速"而某一季同比为负）；"+-"这类符号拼接。

## 2. 评分表（0–3 分，发布要求：无 P0、每项 ≥2、平均 ≥2.5）

**研究（R）**

| 项 | 3 分 | 2 分 | 1 分 |
|---|---|---|---|
| R1 核心判断 | 公司特有、带数字、可被下一期推翻 | 具体但证伪条件弱 | 泛泛的增长/景气描述 |
| R2 驱动拆解 | 逐项有符号量化，区分披露/计算/假设 | 主要项目量化 | 只描述方向 |
| R3 替代解释 | 给出最强替代解释与区分证据（页码） | 有替代解释无区分证据 | 无 |
| R4 利润质量与现金 | 工业企业核对利润质量、现金与营运资本；银行核对信用成本、资本和负债成本，按披露验证 | 缺一项 | 只看净利润 |
| R5 边界诚实 | NOT_CHECKED 清单完整、无越界结论 | 个别遗漏 | 有未支持结论 |

**视觉（V）**

| 项 | 3 分 | 2 分 | 1 分 |
|---|---|---|---|
| V1 五秒可读 | 每图标题+一句话答案即可说出结论 | 多数图可以 | 需要读脚注才懂 |
| V2 图种恰当 | 每图关系与图种匹配，无重复问题 | 一处重复或次优 | 多张同类图堆叠 |
| V3 层级与标注 | 关键金额直标，同比/利润率在旁，次要项收敛 | 标注齐全但拥挤 | 依赖图例/悬停 |
| V4 节奏 | 首屏一张主图，图文交替，反证紧贴图 | 节奏略平 | 卡片网格堆砌 |
| V6 图种多样（EDITORIAL_V2） | 每个重大且可证明的问题都有合适表达，删图会丢失判断 | 有一图重复或证据未充分利用 | 为图数重复绘制，或缺少决定主结论的图 |
| V5 三端原生 | 1440/768/390 各自构图，字号达标 | 768 略挤 | 手机只是缩小 |

## 3. 逐图截图自评流程（每张图都做）

1. 在 1440 和 390 截取该 figure 元素（真实 Noto CJK 字体）。
2. 只看标题和图 5 秒，写下你读到的结论；与 takeaway 对比，不一致就改图或改标题。
3. 检查：最大金额是否最显眼；最小金额是否仍有数字；正负号与颜色是否一致；单位与期间是否在图内或标题下。
4. 检查是否有更简单的图能回答同一问题；如果表格更快更清楚，换成表格或下沉到核对区。
5. 记录问题与修改，重新截图，直到无 P0 且该图 V1–V3 ≥2。

## 4. 发布状态

- `research-preview`：P0 清零，自评达标，源与会计门 PASS，浏览器门 PASS，独立人类二审 NOT_CHECKED（当前所有报告的状态）。
- `source_limited_preview`：存在已披露但未解决的原件矛盾或缺少关键附注，文中显式说明。
- 不存在"顶级""机构认证"等自授标签。只有真实独立财务与视觉审稿记录存在时，才可在 `project-status.json` 的 `review_evidence` 中登记。

## 5. 降低用户干预的自主审美复核证据

对每一个当前 `publication.json` figure 记录：读者五秒内读到的独立结论、真实原始金额与图形语义、层级/留白与颜色语义、真实390及WebKit375可读性、为什么不用更简单的图/替代解释、与至少两份现时同库优秀作品的**具体视觉差距**、本次修订或者保留理由。执行者必须实际打开截图；仅靠几何检测没有资格给 V1/V3/V4 满分。

`editorial-self-review.json` 额外记录 `peer_calibration.peers` 每项的公司代码、当前 HTML SHA、`research_delta` 与 `visual_delta`，以及 `chart_reviews` 的逐图七项说明，供 `research/shared/autonomous_editorial_audit.py --strict` 拒绝泛化稿未完成的自审。该脚本产生修订需求而非视觉美学评分。没有合适的行业/报告期对照时诚实标 `NOT_ESTABLISHED`；不能写虚假同行 benchmark。作者审美自评、其他 AI 独立意见和真实人类二审分别登记。

任何视图/源表改动都使旧 HTML SHA 下的阅读证据失效。每次修订至少比较首屏、主图、完整图序及手机整页；不把图多、文字多、自评分高或没有越界当作顶级审美。历史已发布报告可以作为校准样本，但不继承他们的当前 SHA、研究结论或缺陷。
