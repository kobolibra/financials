# Playbook 02 · 分析框架：AEI 的问题顺序 + A 股会计与取证

App Economy Insights（AEI）公开文章的分析顺序是：业务 → 业务经济性 → 机会 → 风险 → 财务 → 价格/估值（见 `research/01_APP_ECONOMY_INSIGHTS_RESEARCH.md` 的一手链接）。它的财报解读每期固定回答几件事：这季发生了什么（收入/利润结构与同比）、为什么（分部与利润率变化）、管理层怎么看（指引与电话会）、接下来看什么。本 playbook 把这个顺序落到 A 股原始披露上。

## 1. 一份报告必须回答的八个问题

| # | 问题 | A 股证据来源 | 输出 |
|---|---|---|---|
| Q1 | 公司靠什么赚钱？ | 经营情况讨论、收入按产品/行业/地区及成本附注 | 商业机制一段话；收入互斥分类 |
| Q2 | 本期发生了什么？ | 主要会计数据、合并利润表 | 3个首屏指标；完整利润主线 |
| Q3 | 利润为什么和收入走得不一样？ | 两期利润表逐行 | 同比有符号桥；毛利率 pp 变化；最大拖累/支撑项 |
| Q4 | 利润质量如何？ | 非经常性损益表、公允价值、投资收益、补贴、减值 | 扣非 vs 归母 vs 合并；一次性项目清单 |
| Q5 | 利润变成现金了吗？ | 现金流量表及补充资料 | 净利→CFO 全部调节；CFO/净利；销售收现/收入 |
| Q6 | 增长占用了多少资本？ | 应收、存货、合同资产/负债、应付、现金资本开支 | 两时点存量；存货结构；客户集中（注明分母） |
| Q7 | 资产负债表能撑住吗？ | 资产负债表、借款、受限资金、分红 | 资产=负债+权益；净现金/净负债口径；到期结构（有披露时） |
| Q8 | 下一次披露看什么？ | 本期判断 | 三组可证伪检验：盈利、现金、资本 |

可选（只有有独立数据时）：8–12 季趋势、量价拆分、同行对比、估值区间。数据缺失时在文中明确列为 NOT_CHECKED。

## 1b. 文章结构（EDITORIAL_V2，借鉴 AEI 财报文）

1. **钩子**：标题是本期最重要的问题（例："收入增21%、归母利润增42%，毛利率跃升能持续吗？"），副标题给两三个关键数字。
2. **本期一览**：6 条要点（营收、利润率、归母、现金、风险存量、现金构成），随后 KPI 看板图。
3. **损益流向图**：一张图回答"收入如何变成股东利润"。
4. **3–4 个主题章节**，每章 `chapter{kicker,title,summary}` + 1–3 张图：增长（单季柱）→ 盈利（利润率哑铃、增速条、变化桥）→ 现金与资本（余额变动、现金桥）→ 资产负债。
5. **研究判断与上期检验**，最后是重大附注与完整核对层。

每张图写四句话：问题（标题）、结论（takeaway，≤100字）、趋势（trend，图中能看出的走势）、重点（analysis）、反证（counter）。

**趋势叙事必须由拆分后的数据验证。** 把累计数拆成单季后，逐季检查方向再写"加速/放缓"。反例（已修复，FIN-074）：天孚通信三季报原稿写"逐季提速"，但 2026Q2 单季营收同比为 −0.90%；正确叙述是"二季度持平，三季度重新提速"。带符号增速一律用 `signed: true` 的占位符，不在占位符前手写"+"。

## 2. 核心判断的写法

好的判断：**具体、带数字、能被下一期推翻**。
- 好："收入增长形成的毛利增量 {{gp_delta}} 亿元小于财务费用同比恶化 {{finance_drag}} 亿元；若汇率压力缓和后毛利率仍低于上期，利润约束不能归于汇率。"
- 差："公司业绩稳健增长，未来可期。"（不可证伪，无机制）
- 差："AI 需求导致收入大增。"（把行业叙事当因果，未见原文证据）

结构：判断（1句）→ 机制（1–2句）→ 量化（占位符）→ 最强替代解释（1句）→ 证伪条件（1句）。新报告必须把结构写入 `research-brief.json` 并运行 `tools/research_evidence.py` 做来源、会计类型、期间与 Decimal 精确算术审查；不允许用同一句话同时充当机制和最强替代解释。机器通过不证明因果归因成立，独立财经二审仍需人工进行。

## 3. 驱动式模板（按需选用，全部用 Decimal 原始元）

```
Δ毛利 = Σ_i (收入_i,t − 成本_i,t) − Σ_i (收入_i,t−1 − 成本_i,t−1)        # 逐业务（TYPE A）
毛利率变化(pp) = 毛利率_t − 毛利率_t−1
Δ归母 = Δ毛利 − Δ税金附加 − Δ销售 − Δ管理 − Δ研发 − Δ财务 + Δ其他收益 + Δ投资收益
        + Δ公允价值 + Δ信用减值 + Δ资产减值 + Δ资产处置 + Δ营业外净额 − Δ所得税 − Δ少数损益
CFO = 合并净利润 + Σ 全部原始间接调节（原符号）
期末现金及等价物 = 期初 + CFO + CFI + CFF + 汇率影响
简单FCF（分析师定义） = CFO − 购建固定资产、无形资产和其他长期资产支付的现金
CFO/净利（净利≤0 时不定义）
```

把 Δ毛利再分成"收入规模效应"和"毛利率效应"时，用 `research/shared/comparative_economics.py`（交互项平均分配，精确有理数），并写明这是会计归因，不是价格/销量/结构的因果识别。

## 4. 取证清单（每份报告逐项过，结论写进重大附注表）

1. 来源：完整原件、版本、合并口径、审计状态、比较期是否重述。
2. 收入确认：时点/时段、FOB/DAP、寄售、验收；合同负债变化方向。
3. 应收：原值/坏账/净额；账龄；前五大**应收**占比（分母是应收余额，不是收入）；应收票据与背书。
4. 存货：原材料/在产品/库存商品/发出商品；跌价准备存量与本期计提分开。
5. 非经常性损益：按证监会解释性公告的经济实质判断，不机械剔除全部补贴；税后、少数后口径。
6. 现金调节：补充资料全部行逐元闭合；BS 余额变动不能替代调节表。
7. 现金可得性：货币资金 ≠ 现金及等价物；受限资金、定期存款、理财。
8. 资本开支：现金购建 vs 在建工程/固定资产账面变化；票据背书的非现金支付。
9. 融资：短借/长借/租赁负债/应付股利；分红已宣告未支付是负债。
10. 归属：少数股东损益占比变化；少数亏损时归母可能高于合并。
11. 研发：费用化 vs 资本化；开发支出转入。
12. 汇兑：利润表汇兑损益 ≠ 现金流量表汇率影响 ≠ 其他综合收益折算差额。

## 5. 行业路由与实现状态

| 路由 | 适用 | 主要指标 | 新出版器（`source_publication.py`）状态 |
|---|---|---|---|
| `industrial_own_cost_income` | 制造、电子、光通信、半导体、软件、消费、医药、公用事业 | 分业务毛利、费用率、CFO 转换、营运资本、资本开支 | **已实现**（TYPE A 业务图 + 全部 bridge/comparison/balance/components） |
| 工业 TYPE B（仅集团成本） | 分部只披露收入 | 同上，但分部毛利未知 | **未接入新出版器**；旧 V10 出版器有实现（000333 历史案例）。新公司需先扩展适配器 |
| 银行 | 商业银行 | NII、NIM、手续费、信用成本、不良、拨备覆盖、资本充足率 | **未接入新出版器**；旧 V10 有 600036 实现。禁止套工业 CFO/FCF |
| 寿险/财险 | 保险 | 保险服务业绩、CSM、新业务价值、综合成本率、偿付能力 | 只有 601628 专用出版器；新保险公司需独立适配器 |
| 券商/资管 | 证券 | 经纪、投行、资管、自营、两融；净资本 | **未实现** |
| 地产 | 开发商 | 合同负债、预售、受限现金、到期债务、持续经营 | **未实现**（05 手册有 000002 原件测试记录） |
| 多元集团含金融子公司 | 000333、600519 等 | 营业总收入 vs 营业收入；财务公司存款与工业现金分开 | 需要在账本中分开事实，图中明确口径 |

未实现路由的新公司：先运行 `v2_builder.py capabilities` 生成逐行业证据与合法图种清单，按 Playbook 07 判断出版能力。未接入的金融和地产新出版路径在 `scaffold/apply` 默认**拒绝**，不能把工业固定图族当成金融研究框架；只作取证技术探针时用显式 `scaffold --source-probe`，它不具备发布资格。先在 PR 中扩展共享适配器（至少不同发行人和期间的真实原件对抗测试），不得在公司目录下写专用绘图代码。

## 6. 行业关键问题速查

- **光通信/电子**：产品口径（无源/有源/模块）；客户集中；原材料与成品库存；汇兑（外销占比）；资本开支。不得编造 800G/1.6T 结构或客户名。
- **半导体**：产品与定制/IP 服务分开；存货跌价；研发强度；亏损期的现金消耗；政府补助。
- **软件**：订阅 vs 授权 vs 服务；合同负债；股份支付；投资收益对利润的贡献。
- **消费/白酒**：渠道（直销/批发）与产品分层；预收/合同负债；财务公司现金另列。
- **医药**：药品销售、许可收入、其他业务互斥；创新药销售是子集；研发资本化；里程碑款时点。
- **公用事业/水电**：发电量 ≠ 售电量；同控追溯比较期；折旧与财务费用；资本开支与债务。
- **家电/制造**：分部层级（父子不相加）；地区与产品不同维度；汇兑套保；应收与应收款项融资。

## 7. 管理层信息的使用

经营讨论、业绩说明会记录、投资者关系活动记录表可以引用，但必须标为 MANAGEMENT，与 DISCLOSED 事实分开；把管理层解释与数字对照（例如"管理层称毛利率下降源于汇率"→ 用汇兑损益与毛利率变化检验是否足以解释）。管理层指引若存在，下一期文章检验其兑现。
