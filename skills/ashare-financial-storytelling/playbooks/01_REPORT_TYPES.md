# Playbook 01 · 报告类型：季报、半年报、三季报、年报各能做什么

同一家公司的四种定期报告披露深度不同。先判断"这份文件能支持哪些结论和图"，再决定文章结构。用不支持的数据硬做图，是跨期交付不稳定的首要原因。

## 1. 识别与命名

| 封面字样 | `fiscal_period` | `comparative_period` | 审计 | 典型页数 |
|---|---|---|---|---|
| 2026年第一季度报告 | `2026Q1` | `2025Q1` | 未审计 | 10–25 |
| 2026年半年度报告 | `2026H1` | `2025H1` | 通常未审计（少数审阅） | 100–250 |
| 2026年第三季度报告 | `20269M` | `20259M` | 未审计 | 10–25 |
| 2025年年度报告 | `2025FY` | `2024FY` | 审计（核对意见类型） | 150–300 |

- 只接受**完整报告**。"摘要"、英文版、H 股公告、业绩快报都不是原件；快报/预告只能作为对照材料，不能进账本主事实。
- 修订版（"更正后"、"修订版"）要记录公告日期与替代关系；同一期多个版本时以最新更正版为准，并保留旧版 SHA。
- `fin_intake.py init` 会核对封面年份与类型、在前12页寻找证券代码页，并生成以上字段；三季报自动加上单季列声明。

## 2. 各类报告的可用数据

| 内容 | Q1 | H1 | 9M（Q3） | FY |
|---|---|---|---|---|
| 主要会计数据（含扣非、CFO、ROE） | ✓ | ✓ | ✓（本报告期单季 + 年初至今两组） | ✓（三年） |
| 非经常性损益明细 | ✓ | ✓ | ✓ | ✓ |
| 变动原因说明（管理层） | ✓ 简要 | ✓ MD&A | ✓ 简要 | ✓ 完整经营讨论 |
| 合并三表 | ✓ | ✓ | ✓（利润表/现金流为年初至今） | ✓ |
| 母公司三表 | 部分 | ✓ | 部分 | ✓ |
| 现金流量表补充资料（间接法） | ✗ | ✓ | ✗ | ✓ |
| 收入按产品/地区/行业及各自成本 | ✗（偶有） | ✓ | ✗ | ✓ |
| 应收账龄、前五大应收、坏账 | ✗ | ✓ | ✗ | ✓ |
| 存货分类与跌价 | ✗ | ✓ | ✗ | ✓ |
| 前五大**客户销售额**/供应商采购额 | ✗ | 少数披露 | ✗ | ✓（真正的收入集中度） |
| 分季度主要财务指标（Q1–Q4） | ✗ | ✗ | ✗ | ✓（可得 Q4 单季） |
| 审计意见、关键审计事项 | ✗ | ✗（审阅时有审阅报告） | ✗ | ✓ |
| 利润分配预案 | ✗ | 有时 | ✗ | ✓ |
| 研发人员、产能、在手订单、经营数据 | ✗ | 部分 | ✗ | ✓（行业指引要求时） |

## 3. 按报告类型的文章与图

**Q1 / 9M 季报（轻量但不浅）**
- 主图：完整利润主线（营业总收入 → 归母），季报无分部，所以省略 TYPE A 业务毛利图（`publication.json` 不放 `income` family，出版器不会要求分部）。
- 同比变化桥：上年同期归母 → 逐项有符号差额 → 本期归母。
- 利润质量：归母、扣非、合并净利、CFO 两期对比。
- 现金：没有间接法补充资料，**不能画净利→CFO 桥**。改用直接法主要项目（销售商品收到现金、购买商品支付现金、职工薪酬、税费）的两期对比，再画期初→期末现金桥。
- 资本占用：应收、存货、合同负债、应付两时点（期末 vs **上年度末**，不是上年同期）。
- 9M 的单季：只有"主要会计数据"表给出 Q3 单季营收、归母、扣非；在账本中用 `source_column: "本报告期"` 并在 `issuer.flow_columns` 声明为 `2026Q3`。完整的 Q3 单季利润表 = 9M − H1，需要跨文件派生，当前出版器的 DERIVED 只允许同一账本内两项相减，所以**跨报告单季派生目前标记 NOT_IMPLEMENTED**，用文字说明而非伪造图。

**H1 半年报（当前出版器覆盖最完整）**
- 全部图种可用：TYPE A 业务毛利、完整利润链、同比桥、扣非与现金、净利→CFO（全部间接调节）、营运资本、存货结构、现金桥、资产负债、地区构成。
- 期初现金是 2025-12-31，不是 2025-06-30；比较期期末现金另列。

**FY 年报（最深）**
- 在 H1 全部内容基础上增加：审计意见与关键审计事项主题、前五大客户**销售额**集中度（与应收集中度分开）、Q4 单季（FY − 9M 或直接用分季度表）、利润分配与现金分红占归母比例、资本开支与在建工程转固、三年主要会计数据。
- 年报与次年一季报常同日发布：可以作为两篇，也可以在年报文章中用一季报作"下一次披露检验"的首个证据，但两份文件的事实分别入账、分别标期间。

## 4. 比较期与期间命名规则

- 流量（利润表、现金流量表）：本期 vs 上年同期；写"2026H1 vs 2025H1"。
- 存量（资产负债表）：期末 vs 上年度末；写"2026-06-30 vs 2025-12-31"，叫"较年初"，不叫"同比"。
- 比较期被追溯调整（同控合并、会计政策变更）时，用报告中"调整后"列，并在附注表说明调整原因；`600900` 是同控追溯的真实案例。
- 单季 = 累计 − 前一累计，前提是两个期间口径一致、无重述；否则写明不可比。
- 年化：H1 不乘 2 当全年；周转天数需写明平均存量与年化方法。

## 5. 跨期系列（持续出版同一公司）

同一公司换期时：新建一个新的报告期文件夹或新路由（不要覆盖旧期 HTML 的稳定 URL），复用上一期的研究判断作为"本期检验对象"：上期写下的证伪条件逐条打勾或打叉，放进新文章第一屏下方。这是让系列文章持续有判断力、而不是每期从零开始的关键。

目录路由策略（同一公司多期）尚未在 `site/research_catalog.json` 中定型；新增第二期前先在 PR 中提出路由方案（例如 `/300570-2026q3.html` 并在公司卡片列出历史期次），不要擅自改动现有 URL。
