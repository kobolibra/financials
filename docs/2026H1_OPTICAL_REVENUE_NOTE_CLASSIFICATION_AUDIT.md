# 财报披露分类复核：300394 / 300502（2026H1）
更新：2026-11-03 · 依据原始交易所半年度报告物理页及已有完整财务账本

## 本次明确解决的会计问题

早期产业桑基图将“总收入 − 已列产品收入”直接包装成一个“未列示差额（计算）”收入流。尽管数值能使流带守恒，这不是经济业务来源的证据，也没有完成公司财报分部注释的语义核对。本次分别检视管理层分产品披露与财务附注中的收入和成本分类，更新来源字段、单位、分类维度和真正的流带标题；要求必须严格从原始正值分类进行精确守恒，不允许再由算法生成虚假“其他业务”。

## “复核”到底是什么意思，哪些已做，哪些没有？

**第一层：内容原始来源复核（此两项分类已做）**。不沿用图上的标签猜原因，而是重新从原始发行人 PDF 的不同章节找披露原文；独立核对同一行列的**数值、单位、报告期、合并与母公司口径、各类分类维度**；在分位上逐一核对披露收入与成本之和，再回写原始账本、图形、文案、来源表和复现测试。此次两个“其他”差额的来源核对和精确数学勾稽属于这种**明确范围的复核**。

**第二层：机构级重大附注全面复核（七家公司尚未完成）**。依据重大性及行业性质，不是机械阅读每一页，而是逐个独立核查与研究结论相关的完整合并利润表、资产负债表、现金流量表和重要附注：营业收入确认和分部、合同负债和应收、存货及减值、商誉和公允价值、投资收益与非经常损益、税费及少数股东归属、净利润间接法调节的符号和重复项、长期资产/资本开支、关联交易、承诺和或有负债、会计政策和期后事项，以及审计/审阅意见或持续经营提示。银行额外审查净利息、信用减值、贷款阶段/NPL、存款与流动性、监管资本；软件分析订阅/许可及递延收入；白酒分析渠道与财务公司资金；制造业需检查子分部重复、金融子公司、衍生工具；光通信侧重收入分类、应收集中度、库存跌价及现金转换。第二轮需要对原始行列进行交叉检验，不是只靠网页 PDF 页码和金额字符串存在。

**第三层：真实的独立研究和视觉出版复核（未完成、不得冒充）**。不同于首次研究者的另一位专业财务分析人员独立重新抽取关键原文、挑战会计分类与观点、检查最终 HTML 逐图金额/比例/零点/颜色/标签和反证链条，并形成签核记录。模型可以反向验证、测试与提出异议，但**不能冒充不同人类分析师签名或出具法定审计意见**。这不是声称公司账目已被审计，研究中的数字只是基于发行人的公开半年报。

**发布状态**：300394、300502 原先两个收入分类“待确定”的会计问题已经有原始附注支持，不应再写为未解决；七家所有重要附注的完整第二遍审核以及独立专家签核仍应标注 `NOT_CHECKED`，两者不可混同。
