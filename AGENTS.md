## Product

One production library at https://financials-in-visuals.pages.dev/ (`public/index.html`, generated by `site/portal_builder.py` from `site/research_catalog.json`). Each issuer report is a standalone offline HTML page with a stable URL. New issuers or periods are added to the same catalog; never create an alternate homepage or overwrite an existing report URL.

## How work is done

1. Intake the complete original PDF with `skills/ashare-financial-storytelling/tools/fin_intake.py` (SHA, report type, identity page, page text, source-cell facts).
2. Use the original-page leads and Playbook 08 to choose among competing research questions. Record the source-backed lead thesis, strongest alternative, falsifier and exhibit tradeoff in the research brief before building the page.
3. Author `publication.json` and the editorial manifest; publish only through `research/shared/source_publication.py` and the shared renderers. No issuer-specific SVG code.
4. Apply Playbook 09: generate source-supported opportunity matrix and two same-sector/period current-byte peer comparisons, independently inspect every real browser figure for information design, revise before seeking the user's QA.
5. Run `python research/shared/autonomous_editorial_audit.py --code <code> --out work/editorial/issues.json --review-template work/editorial/tasks.json`, then repeat after filling honest peer and per-figure review evidence until `--strict` finds no outstanding revision.
6. Run preflight, tests, clean rebuild, browser QA at 1440/768/390 plus WebKit phone, and a per-figure screenshot self-review against `playbooks/05_QUALITY_RUBRIC.md`.
7. Record gate results in `research/issuers/<code>/release-gates.json` and follow `docs/REPORT_RELEASE_CHECKLIST.md` and `docs/HANDOFF_PROTOCOL.md`.

## Release honesty

Source, accounting, research, visual, browser, GitHub and live production checks are separate gates with `PASS / FAIL / NOT_CHECKED`. CI success is not editorial approval. Independent human finance and visual review stays NOT_CHECKED unless real evidence is supplied. Do not claim "top tier", "surpasses AEI" or all-industry generality. Keep known source discrepancies visible (300308 p139 one-yuan column, 688220 mirror-vs-exchange byte equivalence NOT_CHECKED, insurer management premium ≠ CAS25 service revenue).
