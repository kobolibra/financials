01 / THE MONEY

无源和有源，各自贡献了多少毛利润？

按金额比例拆解收入：每条连续流带都有独立的金额与利润/成本去向。分部披露差额仅作为计算差额，绝不是虚构业务。

2026 H1 / 收入 → 毛利润 + 营业成本 / RMB 亿

来源：天孚通信 2026H1 半年度报告 p22、p61。原值以元精确处理、绘图时按亿展示；各条流带面积与金额严格同比例，非实际收付现金流向。鼠标或键盘聚焦可查看原始数值。

观察：增长结构明显分化

无源收入同比增长77.40%，有源收入下降19.57%。两类产品的毛利率分别为71.90%与47.03%；产品结构和各类内部毛利率提升共同构成值得检验的解释，但原报告没有披露可比的型号级销量、单价和良率，因而无法作严格价格—销量—组合归因。

反面解释：供给与需求需要分开验证

公司称关键物料阶段性短缺影响有源产品提产（p14、p22）。这解释了一种可能的供给限制，但未披露量化的收入损失，也不排除需求、产品结构或定价等其他因素。

05 / TWO-SIDED VIEW

最强的支持证据，也必须接受最强的反面假设。

财报研究不应把公司的解释和分析师的推断混为已被证明的经营因果。

支持 / Supported

  • 无源光器件收入增长77.40%，毛利率71.90%（p22）。
  • 归母扣非净利润同比增长36.76%，非经常性损益约0.18亿元（p10–11）。
  • 经营现金流同比增长64.57%，资本开支现金支出约3.08亿元（p65）。

风险 / Challenged

  • 原材料净额较年初增加约3.97亿元（p112）。
  • 应收及合同资产前五大客户余额占比84.27%，客户匿名（p103）。
  • 公司描述了有源器件材料瓶颈，但无法从半年报量化其因果贡献（p14）。
06 / FALSIFICATION

下一份财报，什么数据能够推翻今天的判断？

只有可证伪、可重复的追踪指标，才算真正完成一次研究。

  • 01
    无源毛利率是否持续

    下一份财报比较无源收入、成本、毛利率；如增长回落且毛利率收缩，则高盈利持续性假设变弱。

    p22
  • 02
    有源产能瓶颈是否改善

    关注有源收入与管理层的物料供应描述；仅增长恢复仍不能单独证明供给是唯一原因。

    p14、p22
  • 03
    原材料库存转化

    比较原材料、在产品、库存商品与跌价准备；是否形成销售还是积压。

    p112–113
  • 04
    应收信用集中与回款

    跟踪前五名应收、账龄、坏账准备和经营现金流；不要将应收集中误写为收入集中。

    p102–103
  • 05
    全球产能与资本回报

    对比资本开支、固定资产、在建工程和产品毛利；设施ROIC仍需更多披露。

    p14、p23、p65
